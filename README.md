Actor Characteristics Game – Project Description

The Actor Characteristics Game is an interactive and user-friendly web application designed to help users explore the personalities, acting styles, talents, and famous movie roles of popular Bollywood and Hollywood actors.

The website is developed using HTML, CSS, and JavaScript. It features an attractive dark-themed interface with a stylish gradient background, actor cards, emojis, and interactive buttons.

Users can search for their favorite actors by entering their names in the search box or click the Show All button to view the complete collection of actors. Each actor is displayed in a separate card containing their name and a unique emoji. By clicking the View Characteristics button, users can discover interesting details about the actor, such as their acting skills, personality traits, screen presence, dancing abilities, and famous movie characters.

The application also provides instant search results, displays a message when an actor is not found, and allows users to hide or view characteristics whenever they want. Its responsive design ensures that the website works smoothly on desktops, tablets, and mobile devices.

Technologies Used
HTML: Provides the structure and content of the website.
CSS: Creates the attractive design, colors, animations, card layouts, and responsive interface.
JavaScript: Handles actor searching, displaying actor information, interactive buttons, and dynamic content.
Main Features
Search for Bollywood and Hollywood actors.
Display all available actors.
Explore interesting characteristics of each actor.
Show and hide actor details using interactive buttons.
Display messages for successful searches and unavailable actors.
Responsive design for different screen sizes.
Attractive user interface with emojis and hover effects.
Objective

The main objective of this project is to provide an entertaining and informative platform where users can learn about famous actors and their unique characteristics. It also demonstrates the practical use of HTML, CSS, and JavaScript in developing an interactive and responsive web application.

Conclusion: The Actor Characteristics Game is a fun and educational web project that combines entertainment with web development concepts. It provides an enjoyable experience while demonstrating important frontend development skills.
